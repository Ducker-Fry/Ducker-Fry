My work sits at the intersection of:

- **C++ systems programming**

- Designing reusable C++ components with clean interfaces

- Turning prototypes into maintainable, documented projects

## Selected Projects

### [FlowScribe](https://github.com/Ducker-Fry/FlowScribe)
A local-first transcription tool for Windows with both **CLI** and **GUI** workflows.  
Built around practical media processing: local files, public URLs, long-form transcription, searchable outputs, and review-friendly export formats.

**Highlights**
- Windows-focused product workflow
- CLI + desktop GUI experience
- queue-based processing and bookmarklet intake
- structured outputs for downstream reuse

### [CppConcurrencyProject](https://github.com/Ducker-Fry/CppConcurrencyProject)
A C++ concurrency-focused project exploring thread-safe queues, reusable interfaces, testing, and packaging.

**Highlights**
- C++20
- concurrent data structure design
- CMake-based library packaging
- testable and reusable queue abstractions

### [MySqlClient](https://github.com/Ducker-Fry/MySqlClient)
A custom MySQL client project built with C++ and CMake, organized around `include/`, `src/`, `tests/`, and third-party integration.

**Highlights**
- database client implementation
- project structure beyond toy examples
- mixed systems/application-level C++ work

### [DNS](https://github.com/Ducker-Fry/DNS)
A DNS learning and implementation project in C, centered on protocol understanding and socket/network fundamentals.

**Highlights**
- low-level networking
- protocol-oriented learning
- systems programming mindset
